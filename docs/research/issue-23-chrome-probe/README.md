# Disposable Chrome boundary probe for Issue #23

This is research instrumentation, not an extension product or a source for production code. It is restricted to the authorized `pl4.forgeofempires.com` game page, requests no privileged extension API permissions, performs no gameplay actions, and sends no data off-device. Its static content-script match still grants access to that exact game host. It reads only `/game/json` XHR responses in page memory and emits bounded booleans about three selected service entries. It does not preserve raw responses, IDs, positions, headers, tokens, or city snapshots.

The probe has two static `document_start` scripts: an isolated bridge and a MAIN-world observer. A service worker checks the content-script sender. The MAIN script emits fixed diagnostic messages, including deliberately malformed examples, to test rejection. The isolated script exposes only counters and booleans as a `data-foe23-probe` attribute on the page root so the experiment can be inspected without reading game responses.

Install only temporarily in an authorized Chrome profile, reload the main-city page once, read the bounded diagnostic attribute, then remove the extension. The owner must approve installation at action time because the script can read a logged-in game page. Do not use the probe in Firefox or other worlds without a separate review. The event path is capped at 128 accepted messages per page; no network requests are created by the probe.

The browser-use policy blocks agent navigation to Chrome's extension manager, so the owner must perform installation and removal manually if this live experiment proceeds. Open Chrome's Extensions page, enable Developer mode if needed, choose **Load unpacked**, and select this folder. After the test, remove **FoE Issue 23 Boundary Probe (Temporary)** from the Extensions page and reload the game tab to restore the page's original XHR/fetch functions. Do not leave it installed for ordinary play.
