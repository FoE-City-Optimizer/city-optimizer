# Codex operations

Start in an isolated branch/worktree and inspect `AGENTS.md`, the assigned role prompt, the GitHub Issue, and linked ADRs. Keep a short working note in the task rather than adding broad repository instructions. Run safe local checks without repeated approval. Do not stage, commit, open a PR, merge, or publish unless the active task authorizes it. For cross-role work, hand off with evidence, validation results, and Follow-up Candidates. The role prompt does not override the Issue, accepted ADRs, or security constraints.
