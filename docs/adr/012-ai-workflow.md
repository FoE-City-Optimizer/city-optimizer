# ADR-012: AI-first engineering workflow

**Status:** Accepted

## Context

Implementation reports follow-up candidates; Backlog Refinement authors successor Issues.

## Decision / proposal

Use role-separated evidence, planning, refinement, implementation, review, verification/security, and merge gates.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
