# ADR-002: TypeScript application layer

**Status:** Accepted

## Context

The charter accepts TypeScript for frontend and initially directs a TypeScript Node backend; specific frameworks remain undecided.

## Decision / proposal

Use TypeScript for extension, web, and application/API layers.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
