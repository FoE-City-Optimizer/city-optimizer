# ADR-003: Python optimization worker

**Status:** Proposed

## Context

The charter recommends Python for solver experimentation but requests benchmarking before permanent adoption.

## Decision / proposal

Spike a separate Python worker through a language-independent contract.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
