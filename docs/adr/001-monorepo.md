# ADR-001: Monorepo architecture

**Status:** Accepted

## Context

The charter explicitly sets this organization; boundaries remain documented in component-boundaries.md.

## Decision / proposal

Use one repository with TypeScript workspaces and an independent Python worker directory.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
