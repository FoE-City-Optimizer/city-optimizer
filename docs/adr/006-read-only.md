# ADR-006: Read-only browser integration

**Status:** Accepted

## Context

A narrow adapter must exclude secrets and unrelated account/social data.

## Decision / proposal

Browser integration acquires minimum required data and never performs gameplay actions.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
