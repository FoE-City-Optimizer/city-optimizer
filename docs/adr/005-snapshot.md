# ADR-005: Versioned Canonical City Snapshot

**Status:** Accepted

## Context

Exact schema awaits verified M1 evidence; generated or validated cross-language representations must share one authority.

## Decision / proposal

Own a versioned snapshot contract independent of raw Forge of Empires responses; validate at every trust boundary.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
