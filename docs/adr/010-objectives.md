# ADR-010: Lexicographic objectives

**Status:** Accepted

## Context

Specific free-space metric and practical search policy need experiments.

## Decision / proposal

Prioritize validity and minimum roads; optimize free-space quality only at a fixed road count, then optional stability.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
