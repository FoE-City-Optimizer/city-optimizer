# ADR-004: CP-SAT feasibility spike

**Status:** Accepted

## Context

This accepts a research spike, not CP-SAT as the production engine.

## Decision / proposal

Evaluate Google OR-Tools CP-SAT on tiny and representative cities, with proof/status and scaling evidence.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
