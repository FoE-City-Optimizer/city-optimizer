# ADR-009: Open-source license

**Status:** Proposed

## Context

Open source is decided; the license is not. Do not add a license file as a false decision.

## Decision / proposal

Owner must choose Apache-2.0, MIT, or a reciprocal option before public release.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
