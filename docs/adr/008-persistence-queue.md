# ADR-008: Persistence and queue direction

**Status:** Proposed

## Context

Select products and deployment topology after a concrete vertical-slice/operations analysis.

## Decision / proposal

Evaluate PostgreSQL and Redis or equivalent for durable job metadata, incumbents, and queueing.

## Consequences and next evidence

Keep implementation within this scope. Any unspecified framework, schema detail, or operational choice requires evidence and a scoped Issue before acceptance. See the [charter](../project/project-charter.md).
