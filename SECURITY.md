# Security policy

Do not open a public issue for a vulnerability that could expose player data or credentials. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the repository owner through a private GitHub channel. The owner must enable and verify private reporting in repository settings. There is no published security email address.

The extension must never collect credentials, cookies, session tokens, unrelated social/chat/account data, or full network dumps. Report suspected collection or upload of such data privately. See [data flow and privacy](docs/security/data-flow-and-privacy.md).
