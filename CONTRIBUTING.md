# Contributing

Start with a scoped GitHub Issue in the existing Engineering Project. Check its dependencies and linked ADRs. Work in a branch or isolated worktree, make a small change, run applicable local checks from `AGENTS.md`, and open a PR referencing one primary issue (`Closes #...`). Keep architectural decisions in ADRs. Use Conventional Commits, such as `docs: clarify city model`.

PRs need review and passing CI before merge; do not push directly to `main`. Describe tests, documentation, security/privacy impact, and structured follow-up candidates in the PR template. The Backlog Refinement role owns successor Issues. See [operating model](docs/development/ai-engineering-operating-model.md).
